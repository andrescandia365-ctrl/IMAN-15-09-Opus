APP.TSX GATE MACHINE (inlined so you never open the tsx)
==============================================================================
File in repo: src/components/app.tsx  — do not attach it.

Gate = hub | wizard | activate | desk | taller

Boot:
- register PWA
- if no user → LandingScreen
- else load IndexedDB session + snap immediately (offline till)
- then loadAccount() + getMyAccess()
- redeem pending license code if any
- merge remote payload with local snap (mergePayload)
- persist session + snap

If loadAccount fails and not Unauthorized: keep local copy, toast "Sin red. El local de este aparato sigue."

Render:
- !user || authFail → Landing
- !hydrated || !access → BootScreen
- !licensed (no vendor, no active license) → ActivateScreen
- licensed && 0 stores → LocalsWizard (forced)
- gate wizard && remaining seats → LocalsWizard
- gate activate → ActivateScreen
- gate taller && vendor → VendorDashboardView
- gate desk → Shell (the till)
- else → HubScreen (pick local)

While gate===desk and hydrated: subscribe Zustand DATA keys → saveLocalSnapshot (IndexedDB) debounce 400ms. If online, pushQuiet(events). NEVER saveKiosk blob on every change.

enterLocal(id):
- setActiveLocalStore
- hydrate local snap if any
- selectStore server
- mergePayload(remote, local)
- if network fails and local exists → open desk anyway
